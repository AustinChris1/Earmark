# Earmark brand assets

Rendered from the same paths as [`Logo.tsx`](../../src/brand/Logo.tsx), so these files
and the site cannot disagree. Colours are the Celo palette taken from celo.org:
forest `#476520`, spring `#56df7c`, prosperity `#fcff52`, ink `#0a0a08`.

| File | Size | Use |
|---|---|---|
| `mark-forest-256/512/1024.png` | square, transparent | the mark on a light background |
| `mark-spring-512/1024.png` | square, transparent | the mark on a dark background |
| `icon-prosperity-512/1024.png` | square, opaque | app icon or avatar, black on Celo yellow |
| `icon-ink-512/1024.png` | square, opaque | app icon or avatar, green on black |
| `wordmark-dark-text.png` | 882x210, transparent | mark plus name, for a light background |
| `wordmark-light-text.png` | 882x210, transparent | mark plus name, for a dark background |
| `og-light.png`, `og-dark.png` | 1200x630 | link preview card |
